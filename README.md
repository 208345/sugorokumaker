# sugorokumaker

## v2.4 での変更点(新ルール追加)

### 1. 通信強化
- 通信が断絶しても残った人でゲーム続行できるように。
- 

### 2. 紫マス(貧乏神)を追加
- マス種別に `4:紫` を追加(白・青・赤・黄・紫の5種類)。
- 紫マスに止まると貧乏神が出現し、その時点で最も所持金の多い他プレイヤーから所持金の30%を奪い取り、さらにその相手とマス目の位置を入れ替える。
- 対象となる相手がいない(全員が0円以下)場合は不発になる。
- 盤面エディタ(`BoardEditor`)でも紫マスを選択・保存・読込できる。

### 3. 借金(マイナス残高)ルール
- 所持金がマイナスになると「借金中」状態になる。
- 借金中のプレイヤーは自分の番が来るたびに、借金残高の10%が利息として上乗せされる(複利)。
- 借金中は特急カード(サイコロ2個)を使用できない。
- 画面上部の情報表示に「(借金中)」のラベルが表示される。

### 4. プレイヤー人数の可変化(3人以上に対応)
- これまで `MAX_PLAYERS = 2` に固定されていた対戦人数を可変にした。
- サーバー起動時の引数でプレイヤー人数を指定できる。
- 通信プロトコルの `UPDATE` メッセージも人数分の座標・所持金・カード枚数・借金状態を可変長で送るよう変更した。
- クライアントの盤面描画・情報表示も人数分に対応(プレイヤーごとに異なる色で表示)。

## 起動方法

```
java SugorokuServer <ポート番号> [プレイヤー人数] [ターン数 | 盤面CSVファイル]
java SugorokuClient <ホスト> <ポート番号>
```

例:
```
java SugorokuServer 12345 3 25       # 3人対戦・25期で終了
java SugorokuServer 12345 2 board.csv # 2人対戦・自作盤面を読込(ターン数はデフォルト20)
```

## v2.0からの変更点(v2.2まで)
### SugorokuClient.java 
- サーバから送信される盤面データ (BOARD_INIT) を受信し、クライアント側の盤面情報を初期化する機能を追加した。
- マスの種類に応じてアイコンを表示する機能を追加した。
- 青マス・赤マス：お金アイコン
- 黄マス：カードアイコン
- ゴールマス：ゴール旗アイコン
- マスの背景色（通常・青・赤・黄）を維持したまま、アイコンを中央に表示するよう描画処理を変更した。
- ゴールマスではゴール旗アイコンを優先表示し、お金・カードアイコンと重複しないよう描画処理を修正した。
- 読み込んだ画像を各マスのサイズに合わせて自動で拡大・縮小して表示するようにした。
- ゲーム画面下部のレイアウトを調整し、ログ表示領域の横幅を縮小した。
- サーバから送信されるサイコロの出目 (DICE) を受信し、移動ボタン横にサイコロを表示する機能を追加した。
- サイコロは画像ではなく、四角形と円を用いた図形描画で表示するよう実装した。

### SugorokuServer.java 
- サイコロを振った際の出目を、DICEメッセージとしてクライアントへ送信する機能を追加した。
