# sugorokumaker_v2.0
すごろくメーカーのv2.0です。v1から発展させて2次元にしてみたけどかなーり仮。Playerの持つ属性としてお金の概念を導入し、マスの効果属性としてサイコロが倍になるアイテムをゲットできるマス、資金がランダムな金額プラスになるマス/マイナスになるマスを作成。ゴールはぴったり入らなきゃいけない仕様で（桃鉄やったことあれば桃鉄と一緒）、誰かがゴールに入ったらランダムな位置に移動します

# 各ファイル詳細（ここから下v1から変えてない）
## Board.java
盤面を管理するBoardクラスが記述されたファイルです。ゲームプレイ時にユーザに対してマス目の効果説明を取得するgetEffectDescriptionメソッドやそれに付随するEffectをset,getするメソッドがあります。また、盤面のcsvファイルを読み書きするためのメソッドsetToFile,loadFromFileもこのクラスに入っています。
<br><br>

## BoardEditor.java
盤面を作成するエディタが記述されたファイルです。JFrameを用いてエディタ画面を描画します。クリック操作でいろいろエディットできるようになっており、ボタンに対応したメソッドが書いてあります。保存ボタンや読み込みボタンが押されたあとの実際のcsvファイル操作は、Boardクラス内のメソッドに投げてます。総マス数の変更にも対応しており、一応マスの描画は総マス数に応じて動的に変更されるようにはなってます。(割と簡易的だけど)  
なお、このエディタプログラムはソケット通信を前提としておらず、これ単体で動かします。
### csvファイルの形式
先頭行が総マス数、2行目以降に各行にマス目番号(0番からの通し番号)、そのマス目での効果(整数値、+ならそのマス目数進み、-なら戻る。0ならなにもなし)がカンマ区切りで記述されます。
<br><br>
  
## Player.java
プレイヤーのことをまとめたクラスPlayerが記述されたファイルです。各プレイヤーはそれぞれプレイヤー番号(id)がサーバより接続時に割り当てられます。プレイヤー1、2みたいな要領。 自身の現在位置もpositionとして保持します。
<br><br>
  
## SugorokuClient.java
クライアント側のプログラムです。JFrameによる描画により、各プレイヤーのゲーム画面を表示します。現状、とりあえず全プレイヤー分の通信が確立されてから全員にまとめて盤面情報がくる関係で、全員が接続するまでは仮のデフォルト盤面が表示されます。画面上には現在の盤面の様子、さいころを振るボタン、その下部にログが表示されるようになっています。基本、操作は手番がきたらサイコロを振るボタンを押すだけ。  
ServerReceiverクラスが、サーバから受け取った情報を処理します。サーバからきたデータの先頭にくるワードに応じてそのデータのあらわすものを判別し、適切な処理を行います。先頭がMSGだったらメッセージとしてログに表示とかね。  
盤面の表示はBoardPanelクラスが担っており、サーバから受け取った盤面情報をもとに総マス目数から1行に描画するマス目数を計算して表示しています。  
プログラム実行時、第一引数にPort番号を整数値で入力して使用します。
<br><br>
  
## SugorokuServer.java
サーバ側のプログラムです。既定のプレイヤー数分接続がされるまで待機し、全員の接続が確立されたら読み込んだ盤面情報をクライアントに一斉送信します(broadcastメソッド)。接続が確立された順に各クライアントにプレイヤーidを付与します。ゲームがスタートしたら、各プレイヤーが持ち回りでターンが進みます。クライアント側からサイコロを振るボタンを押されたことを受信するとサイコロの目をランダムに1~6できめ、その結果に応じてマスを移動します(newPosの更新)。移動がすんだら移動先のマスの効果(int型effect)を参照し、効果があったら適宜反映させターン終了です。各処理毎にクライアントへむけメッセージを送信しています。（先頭をMSGとしてデータ送信。）  
プログラム実行時、第一引数にPort番号を整数値で、第二引数に盤面のcsvファイルを指定します。
