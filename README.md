# sugorokumaker v2.6

## v2.6 での変更点
### エディタ機能の強化
- 赤マス/青マスでの抽選される金額と確率を設定できるように（各赤/青マス間共通）
  - 設定時、確率の合計が100%になっていないと警告が出る
- スタート位置が任意の場所に設定できるように
  - こちらも盤面の外に配置すると警告がでる
- 移動できないマスである「空白マス」の追加。灰色表示
- 操作感の変更。各マスをクリックすると、何の種別のマスにするかを選択するシステムへ変更。
  - 従来：クリックするたびマスの効果が変わるしくみ
- 各物件マスにおいて、そのマスの名前と属している物件を自由に設定できるように
  - 物件の名前と金額、収益率を設定できる
- csv保存時の区切り文字を|のみでなく@も併用するように変更

### ゲームルールの変更
- 総資産の概念を導入。所持金と所有する物件の金額の総計。
- 勝敗も総資産をもとに判定
- ターン表記を、第〇期から△年夏のように変更。
  - 1年度春から始まり、1年で春夏秋冬の4ターン。
- 毎年年度終わりに決算。所持している物件の収益率に応じ収益が手に入る。
- 目的地は物件マスの中からランダムで選定

### その他UIまわりの調整
- Winning!表示を王冠のみに
- 目的地マスの見た目を変更
- カードを使いサイコロが2個になってもサイコロルーレットが正しく2個分表示されるように
- サイコロのアニメーションが終わるまで出目がわからないように出目のMSGを送信しないように変更
- 所有する物件一覧を表示するボタンを追加
  - 現在持つ物件一覧と、次回決算時の予想収益も見られる

## v2.5 での変更点(新ルール追加)
- 通信が断絶しても残った人でゲーム続行できるように。
- **サイコロ演出の強化**: サイコロの出目が決まるまでにスロットのように回転するアニメーションを追加。後半にかけて徐々に回転が遅くなる演出でハラハラ感を向上させた。
- **ターンの視認性向上**: 操作ボタンの下に、現在誰のターンかを示すインジケーター（あなたのターン / 〇〇のターン）を追加し、自分の番（赤色）か待機中（グレー）かが直感的にわかるようにした。
- **順位・勝敗の可視化**: 画面上部のプレイヤー情報で、現在1位（単独トップ）のプレイヤーの文字色をオレンジにし、「👑Winning!」というテキストが表示されるようにした（トップタイの場合は通常表示）。
- **ボタンデザインの改善**: 操作用の各ボタンを角丸（Rounded）デザインに変更し、マウスホバー時に少し色が濃くなるアニメーションを追加して、操作感とデザイン性を向上させた。
